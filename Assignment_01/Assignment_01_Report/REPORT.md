## 3. 全局图像几何变换

### 3.1 基本原理

对二维点 \((x,y)\) 使用齐次坐标表示：

$$
\mathbf{p}=
\begin{bmatrix}
x\\y\\1
\end{bmatrix}.
$$

缩放、旋转和平移可以统一表示为矩阵乘法。尺度因子为 $s$ 时，缩放矩阵为

$$
S=
\begin{bmatrix}
s&0&0\\
0&s&0\\
0&0&1
\end{bmatrix}.
$$

逆时针旋转角度为 $\theta$ 时，旋转矩阵为

$$
R=
\begin{bmatrix}
\cos\theta&-\sin\theta&0\\
\sin\theta&\cos\theta&0\\
0&0&1
\end{bmatrix}.
$$

沿两个坐标轴分别平移 $t_x,t_y$ 时，平移矩阵为

$$
T=
\begin{bmatrix}
1&0&t_x\\
0&1&t_y\\
0&0&1
\end{bmatrix}.
$$

若直接使用旋转和缩放矩阵，变换中心会落在图像左上角。为了使图像围绕自身中心变换，需要先将中心 $\mathbf{c}=(c_x,c_y)$ 平移到原点，完成缩放和旋转后再移回。因此，围绕中心的复合变换可写为

$$
M=T(t_x,t_y)T(c_x,c_y)RS T(-c_x,-c_y).
$$

程序中使用 `cv2.getRotationMatrix2D(center, rotation, scale)` 直接获得包含中心补偿的 $2\times3$ 矩阵。这一函数已经将旋转和等比例缩放合并，之后只需在矩阵最后一列中加入平移量：

```python
h, w = image.shape[:2]
center = (w // 2, h // 2)

rot_mat = cv2.getRotationMatrix2D(center, rotation, scale)
rot_mat[0, 2] += translation_x
rot_mat[1, 2] += translation_y
```

最终通过 `cv2.warpAffine` 完成坐标映射和插值。对输出范围以外的区域使用白色填充：

```python
transformed_image = cv2.warpAffine(
    image,
    rot_mat,
    (w, h),
    borderMode=cv2.BORDER_CONSTANT,
    borderValue=(255, 255, 255)
)
```

水平翻转在仿射变换之后执行：

```python
if flip_horizontal:
    transformed_image = cv2.flip(transformed_image, 1)
```

因此本程序的实际顺序是：**中心缩放与旋转 → 平移 → 水平翻转**。复合变换通常不满足交换律，改变顺序可能得到不同结果。例如先向右平移再水平翻转，与先翻转再向右平移并不等价。

### 3.2 边界处理

旋转或放大后，部分图像内容可能落到原始画布以外。为减轻裁剪问题，程序在变换前根据原图较短边的一半扩展白色边界：

```python
pad_size = min(image.shape[0], image.shape[1]) // 2
```

原图被放置在扩展画布中央，后续旋转中心也按照扩展后的尺寸重新计算。这种处理简单直接，能够为常见尺度和角度提供更多显示空间。不过，当放大倍数较大或平移量接近滑块上限时，仍可能出现内容超出画布的情况。

## 4. 基于控制点的图像形变

### 4.1 控制点输入方式

程序将鼠标点击依次解释为源点和目标点：第 1 次点击记录源点，第 2 次点击记录与其对应的目标点，第 3 次点击记录下一组源点，以此类推。源点、目标点和二者之间的方向分别用不同颜色的点及箭头标记。

设源控制点为

$$
P=\{p_1,p_2,\ldots,p_n\},
$$

对应的目标控制点为

$$
Q=\{q_1,q_2,\ldots,q_n\}.
$$

希望构造一个平滑映射，使每个 $p_i$ 被移动到 $q_i$ 附近，同时让周围像素随控制点连续变化。

### 4.2 采用反向映射的原因

如果把原图像素直接投影到目标图，多个输入像素可能落在同一位置，也可能有目标像素没有任何输入像素与之对应，最终形成重叠或空洞。因此本程序采用反向映射：遍历目标图中的每个像素 $v$，计算它应当从原图的哪个位置 $f(v)$ 取值。

为得到目标域到源域的映射，MLS 计算中使用目标控制点 $q_i$ 作为待拟合域，使用源控制点 $p_i$ 作为采样域。得到映射坐标后，再由 `cv2.remap` 从原图重采样。

### 4.3 相似性 MLS 算法

对于目标图中的任意像素 $v$，距离越近的控制点对它的影响越大。程序使用如下权重：

$$
w_i(v)=\frac{1}{\left(\|q_i-v\|^2+\varepsilon\right)^\alpha},
$$

其中 $\alpha=1$，$\varepsilon=10^{-8}$。加入 $\varepsilon$ 可以避免像素与控制点重合时出现除零。代码随后对权重归一化，使同一像素对应的所有权重之和为 1。

根据权重计算目标控制点和源控制点的加权质心：

$$
q^*(v)=\frac{\sum_i w_iq_i}{\sum_iw_i},
\qquad
p^*(v)=\frac{\sum_i w_ip_i}{\sum_iw_i}.
$$

再将控制点中心化：

$$
\hat q_i=q_i-q^*,
\qquad
\hat p_i=p_i-p^*.
$$

为了在局部保留旋转和等比例缩放特征，程序实现的是相似性 MLS，而不是一般的仿射 MLS。二维向量 $a=(a_x,a_y)$ 的垂直向量定义为

$$
a^\perp=(-a_y,a_x).
$$

归一化因子为

$$
\mu(v)=\sum_i w_i\|\hat q_i\|^2.
$$

对于每个控制点，计算

$$
s_i=\frac{w_i}{\mu}\hat q_i^T(v-q^*),
\qquad
h_i=\frac{w_i}{\mu}(\hat q_i^\perp)^T(v-q^*).
$$

最终映射为

$$
f(v)=p^*+\sum_i\left(s_i\hat p_i+h_i\hat p_i^\perp\right).
$$

该映射会随像素位置改变，因此能够产生局部形变；同时，权重和局部相似变换使形变在空间上连续，避免控制点周围出现明显断裂。

### 4.4 稠密坐标场与重采样

程序使用 `np.meshgrid` 一次性生成目标图的全部像素坐标，并利用 NumPy 广播计算每个像素到全部控制点的距离、权重和质心。最终得到两张与图像等大的浮点坐标图 `map_x` 和 `map_y`：

```python
map_x = f_v[:, 0].reshape(h, w).astype(np.float32)
map_y = f_v[:, 1].reshape(h, w).astype(np.float32)
```

映射坐标被限制在原图范围内，再使用双线性插值生成形变结果：

```python
map_x = np.clip(map_x, 0, w - 1)
map_y = np.clip(map_y, 0, h - 1)

warped_image = cv2.remap(
    image,
    map_x,
    map_y,
    interpolation=cv2.INTER_LINEAR
)
```

双线性插值综合采样位置附近的四个像素，比最近邻插值更适合连续形变，可减少锯齿和块状边缘。将越界坐标裁剪到图像边缘能够避免非法访问，不过较强形变时也可能使边缘像素被拉伸。

### 4.5 输入检查

相似变换至少需要两组有效控制点。程序在控制点少于两组或源、目标点数量不相等时直接返回原图：

```python
if len(source_pts) < 2 or len(source_pts) != len(target_pts):
    return np.array(image)
```

这样可以避免用户只完成一半控制点选择时进入后续计算。界面同时提供 `Clear Points` 按钮，用于清除当前控制点并重新选择。

### 4.6 实验现象与分析

控制点对形变的影响具有明显的局部性。距离目标控制点较近的像素权重较大，因此会较明显地沿控制点方向移动；远处像素受到多组控制点共同约束，变化相对平缓。与单纯对局部区域做平移相比，MLS 不会在区域边界产生突变，而是形成连续过渡。

实验时可分别观察以下情况：

| 实验 | 控制点设置 | 预期现象 |
| --- | --- | --- |
| 局部拖拽 | 两组控制点，其中一组产生明显位移 | 位移附近发生弯曲，远处变化较小 |
| 同向移动 | 多组控制点沿相近方向移动 | 较大区域产生平滑的整体偏移 |
| 相反方向移动 | 两侧控制点向相反方向移动 | 中间区域产生拉伸或扭转 |
| 边界约束 | 在图像边缘增加位移较小的控制点 | 边缘更稳定，局部变形更集中 |

相似性 MLS 对局部形状的保持优于完全自由的逐像素位移，在人脸五官调整、物体轮廓微调等场景中较自然。但形变幅度过大、控制点过近或控制关系相互冲突时，局部区域仍可能出现过度拉伸。另一方面，当前实现同时保存“控制点数 × 图像像素数”规模的中间数组，处理高分辨率图像或大量控制点时，计算时间和内存占用会明显增加。

## 5. 两类变换的比较

| 对比项 | 全局几何变换 | 控制点 MLS 形变 |
| --- | --- | --- |
| 控制方式 | 缩放、角度、位移等全局参数 | 多组源点与目标点 |
| 映射形式 | 整幅图共享同一仿射矩阵 | 每个位置具有不同的局部映射 |
| 适合场景 | 图像校正、旋转、缩放、镜像 | 局部轮廓调整、交互式变形 |
| 计算量 | 较小 | 随图像分辨率和控制点数增加 |
| 主要插值操作 | `cv2.warpAffine` | `cv2.remap` |

第一部分的变换由少量全局参数决定，整幅图的几何关系保持一致；第二部分则由稀疏控制点定义局部约束，映射随空间位置变化。两部分虽然形式不同，但最后都需要解决同一个问题：根据变换关系找到采样坐标，再通过插值计算输出像素。

## 6. 总结

本次作业完成了两种不同层次的图像空间变换。全局变换部分将等比例缩放、中心旋转和平移组合在同一个仿射矩阵中，并补充水平翻转和白色边界扩展；控制点形变部分实现了相似性 MLS，通过距离权重、加权质心和局部相似变换，把少量控制点约束扩展为覆盖整幅图像的稠密反向映射，最后采用双线性插值生成结果。

实验中最关键的两点，一是明确复合变换的顺序及旋转中心，二是区分正向映射与反向映射。前者直接影响全局变换的几何效果，后者则关系到局部形变结果是否会出现空洞。通过交互界面对参数和控制点进行调整，可以较直观地观察这些因素对最终图像的影响。
